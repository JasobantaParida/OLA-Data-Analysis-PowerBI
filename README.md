# OLA-Data-Analysis-PowerBI
## 🚖 1. Project Title / Headline

End-to-End OLA Ride Booking Data Analysis Dashboard

A comprehensive Power BI dashboard built to analyze OLA ride booking data using Excel, Python, SQL, MySQL, and DAX. The dashboard provides interactive insights into bookings, cancellations, revenue, vehicle performance, and customer satisfaction.

## 📌 2. Short Description / Purpose

The OLA Ride Booking Data Analysis Dashboard is an interactive Business Intelligence solution designed to analyze ride booking operations and customer behavior. It transforms raw ride data into actionable insights, enabling stakeholders to monitor KPIs, identify trends, optimize operational performance, and support data-driven decision-making.

## 🛠️ 3. Tech Stack

This project was built using:

- 📊 **Power BI Desktop** – Interactive dashboard development.
- 📂 **Power Query** – Data cleaning and transformation.
- 🧠 **DAX (Data Analysis Expressions)** – KPI calculations and business metrics.
- 🐍 **Python (Pandas & NumPy)** – Data preprocessing and analysis.
- 🗄️ **SQL & MySQL** – Data querying and business analysis.
- 📑 **Microsoft Excel** – Data preparation and validation.

**File Formats**
- `.pbix`
- `.sql`
- `.ipynb`
- `.xlsx`
- `.png`

## 📂 4. Data Source

**Source:** OLA Ride Booking Dataset

The dataset contains:

- Booking ID
- Booking Status
- Customer ID
- Vehicle Type
- Pickup Location
- Drop Location
- Ride Distance
- Booking Value
- Payment Method
- Driver Rating
- Customer Rating
- Cancellation Reasons
- Ride Completion Status


The dataset was cleaned, transformed, analyzed, and visualized to extract meaningful business insights.

## 🌟 5. Features & Highlights

## 📌 Business Problem

Ride-hailing companies generate thousands of booking records every day. Without a centralized analytics solution, it becomes challenging to monitor booking trends, measure operational performance, identify cancellation patterns, evaluate revenue, and understand customer satisfaction.

This dashboard addresses key business questions such as:

- Which vehicle type receives the highest number of bookings?
- What is the overall cancellation rate?
- Which payment methods are most frequently used?
- Which vehicle category generates the highest revenue?
- How satisfied are customers and drivers?
- What are the primary reasons for ride cancellations?

---

## 🎯 Goal of the Dashboard

The dashboard is designed to:

- Monitor key business KPIs in real time.
- Analyze ride booking trends and demand patterns.
- Track customer and driver cancellations.
- Evaluate vehicle-wise operational performance.
- Measure customer and driver satisfaction.
- Support data-driven business decision-making.
